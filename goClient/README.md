# Desktop Client — Moved

The end-user desktop client for WaddlePerf has been consolidated into the
**Penguin Desktop Client** as a plugin module.

**New location:** https://github.com/penguintechinc/penguin
- Module source: `services/desktop/internal/modules/waddleperf/`
- Plugin binary: `penguin-mod-waddleperf`

The infrastructure/server clients (managerServer, testServer, webClient, containerClient) remain in this repository.
